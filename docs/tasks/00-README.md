# Задания для Claude в VS Code: ключевые слова, тексты, Sanity

Выполнять строго по порядку, каждое — отдельной сессией. Перед началом каждой сессии агент читает `CLAUDE.md` и `brief.md` в корне проекта.

1. `01-keyword-research.md` — подбор ключевых слов через DataForSEO (EN, PL, RU) и карта страниц.
2. `02-copywriting.md` — тексты всех страниц по карте, отдельно для каждого языка, в модули `src/content/fallback/*`.
3. `03-sanity-seed-and-switch.md` — выравнивание схем Sanity под модели сайта, загрузка контента в Sanity и переключение сайта на чтение из Sanity.

После каждого шага: владелец проверяет результат, коммитит и пушит сам. Агент не коммитит и не пушит.

## Общие правила для всех заданий

- Сайт закрыт от индексации (`SITE_INDEXING` не задан). Не менять это.
- Никогда не запускать `npm run build`. Проверка — `npm run typecheck` и `npm run dev` (порт 3002).
- Секреты берутся из `.env.local`. Никогда не выводить их значения в консоль, логи, файлы или чат.
- **Конфиденциальность Татьяны:** нигде не называть её текущего работодателя (ни в текстах, ни в JSON-LD, ни в именах файлов), не писать ничего, по чему его можно вычислить (число рынков, число SKU, названия внутренних проектов). Никаких сигналов «открыта к работе», никакой кнопки «скачать CV». Прошлых работодателей (Luxvisage, Fashion House, OMA) называть можно.
- Русское написание имени: **Татьяна Бандюк** (не «Бандзюк»).
- Образование (по дипломам): БГЭУ, специальность «Логистика», логист-экономист (2014); магистратура БГЭУ, «Логистика», магистр экономики и управления (2015); сертификат Tempus Be-Safe (Sapienza CTL + БГЭУ, 2014–2015); сертификат Loughborough University (Knowledge Transfer, Tempus); семинар молодых учёных БНТУ 2016 — лучший доклад, 2-е место. Маркетинга в образовании нет.
- **Заголовки:** каждый H1/H2/H3 понятен сам по себе, вне контекста, называет предмет и действие полностью и содержит ключевую фразу своего раздела. Газетные и абстрактные заголовки («Результаты», «Что дальше», «The fix») запрещены. Правило действует на всех трёх языках.
- Тексты для PL и RU пишутся под запросы своего языка, а не переводятся с английского.
- Рекомендации (отзывы) — только реальные, с разрешения автора. Не выдумывать имён и цитат. Пока реальных нет, остаются плейсхолдеры с пометкой.
- Цифры в кейсах — только от владельца. Если цифры нет, оставить плейсхолдер и отметить в отчёте.
